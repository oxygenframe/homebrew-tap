# oxygenframe/homebrew-tap

Homebrew formulae for [oxframe](https://oxframe.dev), motion graphics as
Rust code.

```sh
brew install oxygenframe/tap/oxframe
oxframe init my-video && cd my-video && oxframe dev --open
```

The formula installs the prebuilt `oxframe` CLI for macOS and Linux (arm64
and x86_64) from the [oxframe-cli releases](https://github.com/oxygenframe/oxframe-cli/releases)
and ffmpeg. oxframe builds your project with cargo, so you also need Rust
([rustup](https://rustup.rs)).

`Formula/oxframe.rb` is generated by `update.sh`; a workflow checks for a new
release every hour, installs it on macOS and Linux and commits it.
